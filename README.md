# Material de estudos

title: Título.            (nome da guia)
h1-6: Cabeçalho.          (quanto maior o número menor o tamanho do título)
p: Parágrafo.

br: Quebra de linha.      (equivalente do \n em outras linguagens)

b: Negrito.
i: Itálico.
u: Sublinhado.
mark: Marca texto.        (amarelo por padrão)
    
img: Imagem.              (busca do campo src="[arquivo]" (se imagem não pode ser encontrada, é trocada com texto em alt="[texto]"))
    
a: Hyperlink.             (Redireciona para o domínio em href="[domínio]", o texto do link é o texto entre a setas)
  target="_blank" cria uma nova guia em vez de carregar a página em cima da atual.
    
button: Botão.
ol: Lista ordenada.
ul: Lista não ordenada.
li: Item de lista.
    
script: Permite uso de arquivo java.

link: Permite uso de arquivo css.

[texto]*X: Escreve [texto] X vezes
Exemplo: br*4 escreve <br> 4 vezes instantanemente
